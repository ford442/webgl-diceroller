# Edge cases and the decisions behind them (#383)

Each case is either asserted by a test or has an explicit decision here. "Test" names
the script; **no-WASM** means the check runs against a build without physics (which is
all a session without Emscripten can run), **needs WASM** means it is asserted only
when dice exist and reports `SKIP` otherwise (`REQUIRE_WASM=1` turns the skip into a
failure, for the full-build CI job).

Observed results are from `build:js:allow-missing-wasm` on headless Chromium with
SwiftShader. A row marked _not run_ was not exercised by anyone yet.
